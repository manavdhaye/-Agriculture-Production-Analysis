# Agriculture Production & Growth Analysis (Power BI)

## Problem Statement
Analyze Indian agriculture data to identify crop trends, regional performance, and sustainability challenges.

## Tools Used
- Power BI Desktop
- DAX
- Excel

## Key Features
- Crop & seasonal analysis
- Climate impact (rainfall, heatwaves)
- Soil health vs productivity
- Market economics & farmer welfare
- Star schema data model

## How to Open
1. Download the `.pbix` file
2. Open using Power BI Desktop (latest version)

## Insights
- Soil health and climate variability explain regional underperformance
- Profitability varies significantly across crops
- Credit access improves yield outcomes
